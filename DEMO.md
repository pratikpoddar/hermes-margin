# Margin: 60-second demo script

**Before recording**
- Make a Google Doc called "Launch plan" with three short paragraphs. Include:
  - one clumsy sentence: "Our product is very good and people likes it a lot because it is fast."
  - one vague line: "We will ship sometime later this year."
- Set `MARGIN_POLL_INTERVAL=3`, use a fast model, and have `hermes gateway` running with the doc already watched.
- Record the browser full screen at 1080p, zoom 125%, with no terminal on screen until the end card.
- Cut every wait down to under a second, and add captions for viewers watching on mute.

| Time | On screen | Caption / voice-over |
|---|---|---|
| 0:00–0:05 | The doc. Highlight the clumsy sentence, comment `@hermes make this crisp`, then Post. | "Your agent, in the comments." |
| 0:05–0:15 | The reply appears and edits in place, from "🪶 reading the doc…" to a proposed replacement. | "Hermes reads the whole doc and replies in the thread." |
| 0:15–0:23 | Type `apply`. The sentence in the doc changes. | "Reply apply, and it edits the doc." |
| 0:23–0:35 | In the same thread, ask: "Does anything else here need fixing?" Hermes flags the vague ship date. | "Every thread is its own session, with memory." |
| 0:35–0:47 | Highlight the vague line, comment `@hermes make this a dated milestone list`. The answer lands. | "Highlight anything. Ask anything." |
| 0:47–0:53 | Quick cut to a Slides comment getting an answer. | "Docs, Slides and Sheets." |
| 0:53–1:00 | End card: "Margin — Hermes in the margins" with `hermes plugins install pratikpoddar/hermes-margin` | "Your model, your Google sign-in. No tokens stored." |

**GIF:** cut 0:00–0:23 to `docs/demo.gif` (about 10 MB or less, 12 fps, 900 px wide).
